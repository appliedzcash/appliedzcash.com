Start here

This page is a reading order for a new builder. Each step has links to the pages to read. Most pages have a live demo in the browser.

Before you start

You need basic programming skills. The Concepts page explains the terms of Zcash. A wallet for Testnet is useful for the demos.

Network status, November 2026

  • Ironwood is a shielded pool. It has been live on Mainnet since July 2026. Use it for new apps.
  • The NU7 upgrade has been live on Mainnet since November 2026. The block time is 25 seconds.
  • zcashd is end-of-life (July 2026). Use Zebra or Zakura for a node, and Zallet for a wallet.
  • A tutorial with 75-second blocks or zcashd commands is out of date.

This list is true in November 2026. The latest status is on zips.z.cash.

The path

  1. Read Smart contracts on Zcash. It has a table with the Zcash pattern for each task of a smart contract.
  2. Read Concepts. Build a unified address in the demo.
  3. Read Payment links. Get test coins (TAZ) from a Testnet faucet. The ZecHub faucet list has the faucets. Then make a payment link and pay it from a wallet on Testnet.
  4. Read Address per customer and Watch-only keys. A shop uses them to find the payment of each customer.
  5. Choose one pattern for your task. The next section has the list.
