Basic

Watch-only keys

A server that receives payments needs a viewing key only. With the viewing key, the server sees the payments and makes new addresses. The spending key stays offline.

Use

  • a shop server that marks orders as paid;
  • an accountant or an auditor who reads the payments of an account;
  • a public dashboard of the donations to a project.

Mechanism

Each key is made from the key above it. The derivation is possible in one direction only. Thus, each key has less power than the key above it:

KeySpendSee payments inSee payments outMake addresses
Spending keyYesYesYesYes
Full viewing key (UFVK)NoYesYesYes
Incoming viewing key (UIVK)NoYesNoYes

A unified key (ZIP 316) is the encoding of a viewing key, like a unified address. The prefix of a UFVK is uview1. The prefix of a UIVK is uivk1. On Testnet, the prefixes are uviewtest1 and uivktest1.

Select the smallest key for each task:

  1. Keep the seed and the spending key in an offline wallet or a hardware wallet.
  2. Give the shop server the UIVK. The server makes addresses and finds payments.
  3. Give an auditor the UFVK. The auditor also sees the payments out of the account.

Limits

  • All or nothing. The holder of a viewing key sees all the past and future payments of the account. To show one payment only, use a payment disclosure (ZIP 311, draft).
  • Permanent access. A key that you give out stays valid. To stop new access, move the funds to a new account. The old payments stay visible with the old key.
  • Balances. A server with the UIVK sees each note in. A server with the full viewing key also sees each spend. The full viewing key is necessary for a balance.

Demo: one seed, three keys

The demo uses the orchard and zcash_address crates, compiled to WebAssembly. It derives the keys of account 0 on Testnet from the seed. It then makes address 0 two times: from the spending key, and from the UIVK only. The first seed is the seed of the demo shop on the other basics pages.

Warning

Type only demo seeds here. The holder of a seed has full control of its funds. Keep real seeds in a wallet.
