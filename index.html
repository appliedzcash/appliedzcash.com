Build apps on Zcash

An app on Zcash can attach data and rules to shielded notes. Anyone can use chain data to verify the data and the rules. We call this near-programmability.

This site gives the patterns for near-programmability. Each pattern has one page. Each page gives the problem, the mechanism, the cost, the spec, a demo and a toy example.

Patterns

  • Bound notes

    Put a hash of app data in the rseed of a zero-value note. Standard wallets can decrypt the note.

  • Polite actions

    Each wallet must try to decrypt each action. Thus, an app must use a small number of actions.

  • Wallet-native orders

    Put an order in the memo of a ZIP 321 payment URI.

  • Canonical action pairing

    Use a keyed sort to put the actions of a bundle in order. The order sets the pairs.

  • Threshold keys

    Give each app role one FROST group key. Any n of m members can sign for the role.

Applied Zcash is a community site. Anyone can propose a pattern. The source is on GitHub.
