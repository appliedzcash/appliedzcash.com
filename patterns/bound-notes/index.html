Pattern

Bound notes

An app puts a hash of its data in the rseed of a zero-value note. ZIP 212 calculates ψ and rcm from rseed. Thus, the note commitment cmx is a commitment to the data. Standard wallets can decrypt the note. Anyone with the data can calculate cmx again and compare it with the chain.

This page is a stub. Later versions will add the mechanism, the cost, the spec, a demo and a toy example.
