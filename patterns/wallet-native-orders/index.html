Pattern

Wallet-native orders

An order is a ZIP 321 payment URI. The memo contains the order. The app shows the URI as a QR code. A wallet that reads ZIP 321 URIs can scan the code.

This page is a stub. Later versions will add the mechanism, the cost, the spec, a demo and a toy example.

Applied Zcash is a community site. Anyone can propose a pattern. The source is on GitHub.
