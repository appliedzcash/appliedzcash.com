Pattern

Polite actions

Each wallet must try to decrypt each action on the chain. Each action that an app adds increases the scan time of all wallets. Thus, an app must keep its number of actions small. For example, an app can use one note for each epoch.

This page is a stub. Later versions will add the mechanism, the cost, the spec, a demo and a toy example.
